🧭 Workflow - Where to find what

Layout

  • Left sidebar: help button (?), Open formula editor, the current model, Open the split by group functionality, active dataset and the controls of the selected tab (for all tabs except DataWrangling).
  • Tabs at the top: Data, DataWrangling, Visualisation, Assumption, Tests, Dose Response analysis, History, Chat.
  • Below the tabs: the results list. Every analysis adds an entry. Remove deletes an entry, Previous plot / Next plot page through plots, Set filename and Save export all results.
  • The help button (?) at the top of the sidebar opens the documentation of the selected tab.

1. Load the data

  • Tab Data, sidebar: Choose CSV File (.csv or .xlsx). When OpenStats runs inside the ELN, the data come from the ELN instead.
  • A file with several tables: choose the table in active dataset.
  • Descriptive statistics (sidebar of Data): Variables to group your data, Which Variables to summarize, Which functions should be applied, then summarize or summarize plot.

2. Define the model

  • Sidebar: Open formula editor opens the window FormulaEditor.
  • Change the model type (optional): Linear, Generalised Linear Model, Linear Mixed Model or Optimization Model.
  • Dependent Variable (dropdown, left): choose the outcome. It is not typed into the formula.
  • Predictors (right): only the right side of the model is built here, without the outcome and without ~. Click the buttons under Variables (the columns of the dataset) and under Functions (+ adds a predictor, * adds an interaction), or type into the text field below them, e.g. conc * Treatment. In a Linear Mixed Model, (1|group) adds a random effect.
  • Under Transformations: log, log10, sqrt, exp, as.factor, poly and I, e.g. log(conc), poly(conc, 2) or I(conc^2) for a quadratic term (conc^2 without I() is rejected). Other transformations (e.g. round, abs) have to be created as a new column in the DataWrangling tab.
  • The status field below shows Status: OK when the predictors are valid.
  • Generalised Linear Model: also choose the distribution family and the link function.
  • Create statistical model sets the model; it is then shown in the sidebar. Close closes the window, the entries are kept.

3. Use only a part of the data (optional)

  • Sidebar: Open the split by group functionality, choose Variable and Variable levels.
  • Remove the filter from the dataset brings back the full dataset.

4. Check the assumptions

Tab Assumption, sidebar. A model has to be defined first.

  • diagnostic plots: residual plots of the model (recommended first step).
  • Shapiro test for residuals of linear model: normality of the residuals.
  • Shapiro test for individual groups: normality within each group.
  • Levene test with Data center of each group: mean or median: equal variances; only for a model with one non-numeric predictor.

5. Run a test

Tab Tests. A model has to be defined first. The sub-tabs in the main area depend on the model and the number of groups: Two groups, More than two groups, Multiple Comparisons, Correlation. The settings and run buttons are in the sidebar.

  • Linear model: choose Test family in the sidebar, Parametric or Non-parametric.
  • Two groups: Confidence level of the interval, Alternative hypothesis; parametric also Are the two variances treated as equal or not?. Run with t test (parametric) or Wilcoxon test (non-parametric).
  • More than two groups: parametric ANOVA or Welch ANOVA (one predictor only); non-parametric Kruskal-Wallis Test (one predictor only) or Permutation ANOVA (Number of Permutations, Seed).
  • Multiple Comparisons: Choose a Post Hoc test and run test (one predictor only), or Adjusted p method and Run pairwise comparisons.
  • Generalised Linear Model: Analysis of Deviance (GLM); comparisons with Choose an adjustment method and run PostHoc test.
  • Linear Mixed Model: ANOVA or Permutation ANOVA; comparisons with Choose an adjustment method and Pairwise comparisons.
  • Correlation: Pearson correlation, Spearman correlation or Kendall correlation.

6. Plot the data

  • Tab Visualisation, main area: choose Boxplot, Scatterplot, Lineplot or Histograms.
  • Sidebar: Y Variable, X Variable, optional Colour Variable, Fill Variable, Split Variable and the axis labels.
  • Main area: Create plot.
  • Plot model draws the fitted model into the plot; it only appears when a model is defined and not for every model type.

7. Calculate new columns

  • Tab DataWrangling: build the expression with the buttons or type it.
  • New column name and Run operation and append to dataset add it as a column.
